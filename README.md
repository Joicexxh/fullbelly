🍽️ Full Belly

A full-stack web application designed to connect food donors with people and organizations in need.

📖 About

Full Belly is a web platform created to facilitate food donations and make it easier to connect donors with people and organizations requesting food.

The project combines a responsive frontend with a Django REST API, user authentication, donation management, and food request management.

The main goal is to create a simple and accessible digital solution that helps connect available food resources with people who need them.

* 👤 User registration

🔐 Authentication

Full Belly uses JWT (JSON Web Token) authentication to securely authenticate users and protect private API endpoints.

Users can register and authenticate through the API before accessing protected resources.

🔌 API Endpoints

The main API resources include:
/api/register/
/api/donations/
/api/requests/
These endpoints are used to manage users, food donations, and food requests.
